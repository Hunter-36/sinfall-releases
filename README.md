# SinFall releases

Builds of **SinFall**, a bullet-hell roguelike where you play one of the seven deadly sins.

Download `SinFall.exe` from the [latest release](../../releases/latest) and run it. It's a single file, with no installer. Saves go to `Saved GamesSinFall` in your user folder.

The game checks this page for new versions and can update itself from the title screen.

The game's source is private, and this repository holds only builds and release notes.
